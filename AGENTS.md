# Human Host modding instructions

This repository holds BepInEx 5 plugins for Human Host (Virtual Matrix Studio,
Steam app 2393970) and the tools used to build them. Parent guidance in
`C:\Users\Admin\Documents\GIT\AGENTS.md` still applies; this file adds the
Human Host rules.

## Layout

- `mods/<ModName>/`: one folder and one `.csproj` per plugin. `mods/HelloHost/`
  is the toolchain smoke test and the template for new mods.
- `tools/`: PowerShell 7 scripts for installing BepInEx and UnityExplorer,
  decompiling game code, and checking the environment. `tools/Common.ps1` holds
  the shared helpers.
- `docs/`: environment facts and how-to notes.
- `research/`: findings about game code, one Markdown file per topic.
- `HumanHostCodebase/`: decompiled game code, gitignored, regenerated by
  `tools/Decompile-GameCode.ps1`. It is its own local Git repo with one commit
  per game build.
- `Directory.Build.props` / `Directory.Build.targets`: shared MSBuild settings,
  game paths, default references, and the opt-in deploy step.

publication. Check both working copies before transferring changes; they are
separate Git repositories and do not synchronize automatically.

## Game facts (verify before relying on them)

Recorded 2026-09-19. The game is in early access and updates often. Re-check with
`tools/Get-ModEnvStatus.ps1` and the BepInEx log instead of trusting this list.

- Install: `C:\Steam\steamapps\common\Human Host`. Override per machine in
  `GamePaths.local.props`.
- Unity 2022.3.62f3, Mono scripting backend, HDRP. Game version 0.8.311, Steam
  build 25407931.
- BepInEx 5.4.23.5 (Doorstop 4.5). BepInEx 6 is not used: it is still a
  pre-release, and BepInEx 5 is the version for Unity Mono games.
- Game code is split across about 48 developer-named assemblies (`Player`,
  `Creature`, `Build_System`, `Mgr_Hub`, `SaveData`, `UI`, ...), not only
  `Assembly-CSharp`. The game ships PDBs, so decompiled code keeps local names.
- The player's install also has third-party plugins managed by HHMM (Human Host
  Mod Manager), including `ModMenu`, `PendingFilePatcher` and the `*.hhmm-i18n.json`
  files.

## Rules

- Never commit or push decompiled game code, game DLLs, or anything copied out of
  the game folder. Mods reference game assemblies with `Private="false"` so they
  are never copied to build output.
- Do not edit, move, or delete third-party plugins or their configs in the game's
  `BepInEx` folder. Only touch folders this repository deploys
  (`BepInEx\plugins\<AssemblyName>\`) and the tools it installs.
- Check that the game is closed before deploying or changing BepInEx files.
  Never close the game for the user without asking; it may have unsaved progress.
- Target `netstandard2.1` (set centrally). Add game assemblies with
  `<HumanHostRef Include="Player" />` instead of hand-written `HintPath`s.
- Plugin GUIDs use `rkgamemods.humanhost.<modname>`, lower case.
- Before patching a game method, find it in `HumanHostCodebase/` and cite the
  type and member in the mod's notes. Do not guess member names; the game
  renames fields between builds (see the HarmonyX "Could not find field"
  warnings other mods produce).
- Machine-specific settings, secrets and local overrides go in gitignored files
  (`GamePaths.local.props`, `*.local.*`, `.local/`).

## Commands

```powershell
dotnet build HumanHostMods.slnx -c Release                         # build all mods
dotnet build mods\HelloHost -c Release -p:DeployToGame=true        # build and deploy one mod
.\tools\Get-ModEnvStatus.ps1                                       # environment and last-log check
.\tools\Install-BepInEx.ps1 [-Version 5.4.23.5] [-WhatIf]          # install or upgrade BepInEx
.\tools\Install-UnityExplorer.ps1 [-Remove]                        # in-game inspector (F7)
.\tools\Decompile-GameCode.ps1 [-All] [-Assemblies Player,UI]      # refresh HumanHostCodebase
```

## Validation

- `dotnet build HumanHostMods.slnx -c Release` with 0 warnings and 0 errors.
- For runtime changes: deploy, launch, and confirm in `BepInEx\LogOutput.log`
  that the plugin's load line appears and no new `[Error` or `[Fatal` lines do.
- After a game update, run `tools/Decompile-GameCode.ps1`, then
  `git -C HumanHostCodebase diff HEAD~1 --stat` to see what changed.
